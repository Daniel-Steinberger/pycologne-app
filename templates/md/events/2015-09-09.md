# PyCologne Treffen September 2015

**Datum:** 09.09.2015, 19:00 Uhr
**Ort:** Chaos Computer Club Cologne (C4), Köln

**Anwesend:** 17 Personen

Ein Abend mit einem großen Tastaturen-Showcase, einem Bericht von der Python
Unconference in Hamburg, Rebecca Breus Lightning Talk zu CodeCombat und Nils
Geys Vortrag über eine selbstgebaute Mailinglisten-Software in Python.
Außerdem eine Diskussion über MicroPython auf ESP8266-Boards und Hinweise auf
den Linux Presentation Day und den Software Freedom Day.

## Organisatorisches

- Mailingliste ist erster Anlaufpunkt für Kommunikation!

## Präsentationen

### Mini-Mailingliste - Nils Gey

[Folien, Repository, Webseite](http://foo)

Kurzes Python-Skript basierend auf der IMAP-Bibliothek, implementiert eine
händisch verwaltete Mailingliste für das persönliche Umfeld.

Es wird heiß über modulare versus skriptorientierte Programmierung bei
kleinen Projekten diskutiert. Python bringt alles für modulare Programmierung
mit, viele empfehlen, von Anfang an modular zu bauen, zum Beispiel mit einer
`__main__()`-Funktion.

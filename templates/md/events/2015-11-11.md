# PyCologne Treffen November 2015

**Datum:** 11.11.2015, 19:00 Uhr
**Ort:** Chaos Computer Club Cologne (C4), Köln

**Anwesend:** 17 Personen

Vier Präsentationen: Christian Geier zu Python in vim, Christopher Arndt zum
Time-Tracker Watson und zu einer Tablet-Fernsteuerung für X Windows, sowie
Thomas Koch zum Anzeigesystem LaMetric mit Python. Dazu Ankündigungen zu
mehreren Data-Science-Meetups und der Hinweis, dass Python 3.5 erschienen ist,
aber noch nicht von allen Projekten unterstützt wird.

## Präsentationen

### Python mit vim - Christian Geier

- IDEs haben viele Komponenten, vim kann die Komponente Source-Code-Editor
  übernehmen.
- Mit vielen verschiedenen Plugins kann man vim alle benötigten Features
  beibringen.
- Christian zeigt seine Konfiguration der Plugins als Beispiel.
- <http://lostpackets.de/talks/python_vim_pycologne2015/python_vim_pycologne2015.slides.html>

### Time Tracker Watson - Christopher Arndt

- Timetracking mit Watson in Python.
- Kann bequem von der Konsole die Arbeitszeit an Projekten tracken und vor
  allem als Report ausgeben.
- Noch unter aktiver Entwicklung, am besten von GitHub von Chris
  (SpotlightKid) oder dem Hauptentwickler pullen.
- [Chris' Fork auf GitHub](https://github.com/SpotlightKid/watson) (Branch
  "local" für alle neuen Features),
  [Upstream](https://github.com/TailorDev/Watson)
- Einwurf TKo: Ähnlich zu Watson ist toggl-cli, ein CLI-Client zu
  [www.toggl.com](https://www.toggl.com) in Python: <https://github.com/drobertadams/toggl-cli>

### LaMetric mit Python - Thomas Koch

- [Fernsteuerbares Anzeigesystem, Uhr, Internetradio](https://lametric.com),
  179 $
- [Nachrichten an Thomas schicken](http://message-me-at-home.appspot.com)
- Code-Repository der gezeigten "message-me"-App (Flask-App auf GAE):
  <https://github.com/tommykoch/msgboard>
- Python-Projekt zur Anzeige von Stromverbrauch auf dem LaMetric-Gerät:
  <https://github.com/riccardo/py-jemma-lametric-home-consumption>
- IFTTT-Gateway für LaMetric (via WordPress):
  <http://lametric.littledinky.com/>
- Zur LaMetric-Developer-"API" (und Roadmap):
  <http://help.lametric.com/support/discussions/topics/6000021790>

### Tablet als Custom-Remote-Tastatur für X Windows nutzen (via touchosc2midi) - Christopher Arndt

- [Chris' Fork von touchosc2midi](https://github.com/SpotlightKid/touchosc2midi)
  ([Upstream](https://github.com/velolala/touchosc2midi))

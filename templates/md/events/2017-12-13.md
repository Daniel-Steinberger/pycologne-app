# PyCologne Treffen Dezember 2017

**Datum:** 13.12.2017, 19:00 Uhr
**Ort:** Chaos Computer Club Cologne, Heliosstr. 6a 50825 Köln ([Anfahrt](/join))

**Anwesend:** ca. 18 Personen

Henning stellte den Weg von Microservices zu Fastgenomics mit Docker vor,
Christopher hielt zwei Vorträge: einen zur Linux-Shell Termux auf
Android-Geräten und einen zu seinem Redis-Client PicoRedis für MicroPython.
Dazu ein umfangreicher Rückblick auf Neuigkeiten aus der Python-Welt, von
Type-Annotation-Tools bis zu SQLite-Performance.

## Termine

- Python-Barcamp 2018 findet am 7. und 8. April 2018 statt, Website kommt
  noch.
- 3. Januar: Ende des Call for Talks für die PyCon US (findet im Mai statt).

## Neuigkeiten aus der Python-Welt

- Automatisches Erzeugen von Type Annotations:
  https://github.com/dropbox/pyannotate
- Als Plugin für pytest: https://github.com/kensho-technologies/pytest-annotate
- pytest 3.3
  (https://docs.pytest.org/en/latest/changelog.html#pytest-3-3-0-2017-11-23):
  erfasst jetzt auch Logging-Output
- pyschemes (https://github.com/shivylp/pyschemes): validiert Datenschemata
- tt (https://github.com/welchbj/tt): Toolkit für die Arbeit mit Truth
  Tables in Python
- Going fast with SQLite and Python:
  http://charlesleifer.com/blog/going-fast-with-sqlite-and-python/
- NumPy wird 2020 den Support für Python 2.7 einstellen:
  https://github.com/numpy/numpy/blob/master/doc/neps/dropping-python2.7-proposal.rst,
  "Why is this news to begin with??"
- netgraph, ein NetworkX-Fork für schönere Netzwerk-Plots:
  https://github.com/paulbrodersen/netgraph
- Flake8-Regeln mit Beispielen erklärt: https://lintlyci.github.io/Flake8Rules/
- Intro to Python's pathlib: http://pbpython.com/pathlib-intro.html
- JupyterCon-Videos sind online:
  https://www.youtube.com/playlist?list=PL055Epbe6d5aP6Ru42r7hk68GTSaclYgi

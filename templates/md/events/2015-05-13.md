# PyCologne Treffen Mai 2015

**Datum:** 13.05.2015, 19:00 Uhr
**Ort:** Chaos Computer Club Cologne (C4), Köln

Christopher Arndt stellte Python-in-a-Box vor, ein MicroPython-Board für 15
Euro, Anton Kasyanov sprach über asynchrones Programmieren mit asyncio und
aiohttp, und Daniel Hepper zeigte in einem Lightning Talk den WhatsApp-Zugriff
mit yowsup. Dazu Pläne für einen pyCologne-Stand auf der FrOSCon, eine
Diskussion über Variablen-Scopes in Closures und mehrere Ankündigungen.

**Anwesend:** 25 Personen

## Organisatorisches

FrOSCon: Reimar wird einen Stand für pySV und einen für die pyCologne
beantragen, außerdem einen Projektraum für einen Tag (Samstag).

## Vorstellungsrunde

Chris begrüßt die Anwesenden im Namen der pyCologne, Johannes im Namen des
C4. Es folgt eine Vorstellungsrunde, viele Softwareentwickler (Überraschung!)
und Physiker. Zwei Personen sind zum ersten Mal dabei.

## Präsentationen

### Python in a Box für 15 Euro - Christopher Arndt

[MicroPython](http://micropython.org) auf dem STM32F4Discovery-Board (14 Euro
exkl. MwSt. bei Mouser).

- Billiger als ein Arduino, aber leistungsfähiger und programmierbar in
  Python
- Code wird über USB-Massenspeicher deployt
- Interaktive MicroPython-Konsole über serielles Terminal (Interpreter läuft
  auf dem Mikrocontroller)
- Für typische Anwendungen von Mikrocontrollern:
    - Roboter
    - Heimautomation
    - Controller für musikalische Anwendungen (MIDI) oder interaktive
      Software (Game-Controller etc.), usw.
    - Lichtsteuerung
    - und, und, und

Auf der Chaos Cologne wird es einen Workshop zum STM32F4-Board geben. Auf
<https://1c2.prezale.de/products?locale=de> kann das Board für 20 Euro bestellt
werden.

[Repository](https://github.com/SpotlightKid/micropython-stm.git) mit Folien
(IPython Notebook) und Code-Beispielen.

### Async IO mit aiohttp - Anton Kasyanov

<http://www.slideshare.net/mind1master/aiohttp-pycologne-15-may>

<http://antonkasyanov.com/>

Asynchrones Programmieren: Ein Thread arbeitet während der Wartezeit auf I/O
an anderer Stelle weiter.

- Erhöht die Performanz, falls I/O der Bottleneck ist

asyncio: Sockets, Netzwerkstreams. aiohttp: HTTP, Client und Server,
Datenbanken. Unterstützung für Websockets, RPC.

PEP 493 mit neuer Syntax für die Definition asynchroner Funktionen und dem
neuen Keyword `await` anstatt `yield from`.

### Lightning Talk: WhatsApp - Daniel Hepper

API-Zugriff auf WhatsApp mit Python mittels
[yowsup](https://github.com/tgalal/yowsup/).

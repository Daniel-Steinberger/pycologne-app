# PyCologne Treffen März 2018

**Datum:** 14.03.2018, 19:00 Uhr
**Anwesend:** 13 Personen

Volker Till stellte in einem Lightning Talk das Content-Management-System
Plone vor, von Headless-Betrieb bis React- und Angular-Frontends. Daneben ging
es um die Anmeldung zum PythonCamp samt Code of Conduct, einen Bericht vom
OpenDataDay zur Luftverschmutzungsüberwachung und mehrere technische
Diskussionen, etwa zu Code-Review und Backup-Systemen.

## Lightning Talks

### Plone - Volker Till

- Referent: Volker Till, <http://till.net>
- tl;dr: Plone ist großartig auf vielen Ebenen.
- Anliegen: Mitmachen.
- Auch für kleinere Projekte geeignet, wenn eine Zugangsbeschränkung nötig
  ist, sonst Overkill.
- Headless Plone, React- und Angular-Frontends umsetzbar.
- Ionic-Frontends für mobile Apps.
- Siehe auch die Plone-Conference-Talk-Videos: <http://2017.ploneconf.org> und
  <http://2016.ploneconf.org>

## Diskussionen

- Erfahrungsberichte über Code-Review (Stephan)
- Testing-Feature: python -W all (Kai)
- PyFilesystem2
- Backup Bouncer Test Suite: <https://github.com/n8gray/Backup-Bouncer>, gedacht
  für das Testen der Besonderheiten von macOS unter rsync bei inkrementellen
  Backups (ACL et cetera). Enthält daher eine ganz nette universelle
  Beispieldaten-Generierung, um Input-Daten für Tests gegen Dateisysteme zu
  generieren. Dabei können Testimages unter verschiedenen Dateisystemen
  generiert werden, um dann die Ergebnisse zu diffen.
- Borg Backup System
- Definition of Done
- Code Style Guide

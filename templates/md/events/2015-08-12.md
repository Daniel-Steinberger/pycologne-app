# PyCologne Treffen August 2015

**Datum:** 12.08.2015, 19:00 Uhr
**Ort:** Chaos Computer Club Cologne (C4), Köln

**Anwesend:** 14 Personen (Sommerloch)

Eine Diskussion über einen einfachen Key-Value-Store in Python, ein spontaner
Vortrag über Tastaturen von Christian und eine Demo zum Bau einer
CI-Ampel für Jenkins mit Raspberry Pi von Thomas. Dazu Hinweise auf Type
Hinting in Python und den neuen Compiler Nuitka.

## Diskussion

Key-Value-Store mit Python, Keys als Strings (hier: Wörter), Values als
Floats (hier: Spaminess).

Vorschläge:

- [shelve](https://docs.python.org/2/library/shelve.html)
- [ZODB](http://www.zodb.org/en/latest/)
- [SQLite](http://sqlite.org) ist super für Objekte von bekannter Länge
- dict einfach picklen
- Keys hashen (konstante Länge) und als Numpy-Array schreiben
- NoSQL-Datenbanken nur gut, wenn Values ungleich groß sind

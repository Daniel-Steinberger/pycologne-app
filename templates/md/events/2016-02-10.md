## Präsentationen

### Einfaches Rechtschreibprogramm - Rebecca Breu

- Einfache Rechtschreibprüfung für "Platt" in wenigen Zeilen Python möglich
- Zunächst müssen die Wörter eingelesen werden
- Lookup von Wörtern via set
- difflib bietet diff-ähnliche Ausgabe von Unterschieden zwischen Dateien,
  das hat den Vorteil einer fuzzy Search
- Fertige Bibliothek für Rechtschreibprüfung:
  [PyEnchant](http://pythonhosted.org/pyenchant/)
- Für Teilaufgaben wie Stemming und Klassifikation: <http://www.nltk.org/>
- Schöner Artikel zum Thema: <http://norvig.com/spell-correct.html>

### TensorFlow - Andreas Schreiber

github.com/tensorflow

- ist eigentlich eine Machine-Learning-Bibliothek
- entwickelt und veröffentlicht von Google
- implementiert in C++, Teile in Python
- API etwas komplizierter als zum Beispiel SciKit Learn
- soll sehr skalierbar sein (mehrere Rechner, Grafikkarten, Smartphones)
- Portierbarkeit soll hoch sein
- kann mit n-dimensionalen Tensoren rechnen
- Namensgebung: Daten (Tensoren) fließen durch Algorithmen
- Programm wird als Graph gespeichert (bestehend aus Daten und Operatoren)
- wird erst ausgewertet, wenn "run" gestartet wird

## Lightning Talks

### clone-gist - Christopher Arndt

Ein kleines Python-Skript, um alle Gists eines GitHub-Accounts als
Git-Repositories zu klonen.

Source: <https://gist.github.com/SpotlightKid/042491a9a2987af04a5a>

Das Skript zeigt, wie eine relativ komplexe Aufgabe (Kommandozeilenargumente,
HTTP-Request, JSON-Parsing, Aufruf externer Programme) in Python in wenigen,
gut lesbaren Codezeilen gelöst werden kann.

## Notiz: New-Style- und Old-Style-Klassen

Zum Unterschied zwischen New-Style- und Old-Style-Klassen, siehe auch
<http://docs.python.org/2/reference/datamodel.html#new-style-and-classic-classes>

```
Python 2.6.6 (r266:84297, Aug 24 2010, 18:46:32) [MSC v.1500 32 bit (Intel)] on win32
>>> class test():
...     pass
...
>>> type(test)
<type 'classobj'>
>>> class test2(object):
...     pass
...
>>> type(test2)
<type 'type'>
```

Unter Python 2.7 im IPython:

```
In [16]: class NewStyle(object):
   ....:     pass
   ....:

In [17]: ns = NewStyle()

In [18]: type(ns)
Out[18]: __main__.NewStyle

In [19]: type(ns).__mro__
Out[19]: (__main__.NewStyle, object)

In [20]: class OldStyle():
   ....:     pass
   ....:

In [21]: os = OldStyle()

In [22]: type(os)
Out[22]: instance

In [23]: type(os).__mro__
Out[23]: (instance, object)
```

### Type Hinting in Python 3.6 - Henning Dickten

- Ab Python 3.5
- Type Hints mit "myvar: int"
- Mit Contract-Decorator bessere Fehlermeldungen, oder Modul mypy
- Libraries können Autovervollständigung an Typen anpassen
- Docstrings (Sphinx) mit Contracts statt direkt in der Funktion
- Funktionen können nun auch mit dem Overload-Decorator überladen werden
- Eher für bessere Dokumentation geeignet, weniger für Performance

# PyCologne Treffen Januar 2014

**Datum:** 08.01.2014, 19:00 Uhr
**Ort:** Chaos Computer Club Köln, Heliosstraße 6a, Köln-Ehrenfeld

Ein Abend mit fünf Lightning Talks, von Micro Python über QtSql bis
pymove3D, dazu Rebecca Breus Vorstellung ihres Buchs "Hacking mit Python"
und ihres selbstgeschriebenen Debuggers. Außerdem ein Stimmungsbild zu
Python 3 gegenüber Python 2 und zahlreiche Ankündigungen zu Konferenzen und
Terminen im Frühjahr 2014.

## Stimmungsbild: Python 3 vs. Python 2

- Wer setzt Python 3 ein? Etwa 30 Prozent.
- Wer hat Python 3 schon mal ausprobiert? Fast alle.
- Wer Python 3 einsetzt, setzt auch weiterhin Python 2 ein? So ziemlich auch
  diese 30 Prozent.

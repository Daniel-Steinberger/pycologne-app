# PyCologne Treffen November 2013

**Datum:** 13.11.2013, 19:00 Uhr
**Ort:** Chaos Computer Club Köln, Heliosstraße (C4)

Ein gut besuchter Abend mit vielen neuen Gesichtern: Chris stellte vier Bücher
vom dpunkt.verlag vor, aus denen gleich zwei künftige Vorträge entstanden. Dazu
kamen Ankündigungen zum PythonCamp 2014, Neuigkeiten zu pip und vier Lightning
Talks von distutils-Erweiterungen über pandas bis Cython im IPython Notebook.

## Bücher

Chris stellt vier Bücher vom dpunkt.verlag vor. Johannes erhält das Git-Buch und

## Neuigkeiten zu Python

Von Chris: pip installiert seit Version 1.4 keine Pre-Releases mehr, dafür ist
nun die Option `--pre` nötig. Es folgt eine Diskussion über
Abwärtskompatibilität. Hinweis auf die pip-Dokumentation online, "a tool for
installing and managing Python packages": http://www.pip-installer.org

### IDE-Vergleich: Spyder - Hubert

Version 2.1.10:

- Python 2.7.3, Qt 4.8.2, PyQt4 (API v1) 4.9.3
- Über aptitude unter Wheezy installationsfähig
- Diese Version verfügt aber leider nicht über Code Completion
- Spyder ist aber im Installationsumfang von Anaconda 3
  (http://continuum.io/downloads#py34, IDE für Python 3.x) enthalten,
  kollidiert aber dort mit den systemseitig installierten Qt-Bibliotheken.

Spyder 2.3.1:

- Python 3.4.2, Qt 4.8.6, PyQt4 (API v2) 4.11.2
- Über aptitude unter Jessie installierbar.
- Verfügt über Code Completion, benötigt dazu aber rope, welches unter Jessie
  (noch) nicht paketiert ist.
- Abhilfe: Installiere Anaconda3 als User (Download von continuum.io, dann:
  `bash Anaconda3-4.2.0-Linux-x86.sh`)

```
cd ~/anaconda3/bin; ./spyder
```

- Danach `pip3 install rope_py3k`

Spyder 2.3.2 verfügbar seit 03.12.2014:

- Unter Debian aber noch im Zweig experimental (Stand: 05.01.2015)
- Neuerungen: siehe http://spyder-ide.blogspot.de/

Downloads, Bug Reports und Feature Requests: http://spyderlib.googlecode.com
Diskussionen: http://groups.google.com/group/spyderlib
Dokumentation: https://pythonhosted.org/spyder/

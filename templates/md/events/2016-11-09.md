## Vorträge

### Reproducible Science with Python - Andreas Schreiber

Vortrag von der PyConDE in München. Reproduzierbarkeit ist oft abhängig vom
System, auf dem gerechnet wird (System-Libraries). Provenance:
https://www.w3.org/2011/prov. Aus der Kunst: die (Besitzer-)Historie ist sehr
wichtig bei Kunstgegenständen. Node-Link-Graphen stellen den Prozess der
Erstellung einer zum Beispiel Grafik dar. Provenance-Graphen sind gerichtete
azyklische Graphen (DAG) und können in speziellen Graph-Datenbanken
abgespeichert und mit speziellen Abfragesprachen abgefragt werden (zum
Beispiel Neo4j, ArangoDB et cetera).

Provenienz mit Python sammeln, Library: prov (github.com/trungdong/prov). Im
Gegensatz zu Logging gibt Provenance Abhängigkeiten an.
[noworkflow](https://github.com/gems-uff/noworkflow) erleichtert das
Provenancieren.

### Graph-Datenbanken mit Python nutzen - Stefan Bieliauskas

- ArangoDB: eine Kölner Datenbank, in C geschrieben, nutzt SQL und bietet so
  bekanntes Verhalten.
- Neo4j: in Java geschrieben, Open Source.
- OrientDB: ebenfalls in Java, kann Live-Updates.

Python mit Neo4j: Neo4jRestClient, Py2neo, neo4j-driver (offiziell von
Neo4j).
